This folder contains the application pages:
- RecipeList.jsx: Displays a grid of recipe cards with search via URL query (?q=...).
- RecipeDetailPage.jsx: Shows an individual recipe with ingredients and steps.
- AddRecipe.jsx: Protected form to add a recipe (stubbed submit).
- SignIn.jsx: Figma-derived sign-in page with onSignedIn callback, navigation.
- SignUp.jsx: Registration page styled similar to SignIn.
- ForgotPassword.jsx: Password recovery request page (stubbed).

Styling uses src/styles/common.css and sign-in.css tokens to remain consistent and minimal.
